# Ohio University Attendance App

A Streamlit and Supabase-based attendance management system designed for university classroom attendance tracking.

## Features
- Student sign up with Ohio University email
- Secure login
- Check in / check out
- Dynamic course entry
- Admin-only dashboard
- Live class monitoring
- Attendance records export
- Attendance analytics

## Tech Stack
- Python
- Streamlit
- Supabase
- PostgreSQL
- GitHub

## My Role
Designed and developed the full application workflow, including authentication, attendance logic, admin controls, analytics, and UI styling.
